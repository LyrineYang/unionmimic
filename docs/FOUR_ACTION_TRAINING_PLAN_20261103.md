## 1. 本轮固定四项，不继续拆成微动作课程

保留Sharpa 22关节、固定手腕、Isaac Gym。建议新增套件统一使用一支与参考尺寸匹配的笔，四项任务共用同一物体、物理参数与控制器；旧corner block持续旋转实验保持原配置，作为历史回归对照。换成一支笔是本提案的明确适配决定，不是已经完成的操作，也不是多物体训练。

| ID | 类型 | 完整任务 | 主要评估 |
| --- | --- | --- | --- |
| C1 | 能力验证 | 给定目标方向，笔在手内完成重定向并稳定保持；目标方向采样覆盖不同幅度/方向 | 到位、保持成功率，方向误差、过冲、到位时间 |
| C2 | 能力验证 | 追踪期间受到一次预设扰动，重新稳定抓持并恢复目标方向；扰动时刻/冲量固定分布 | 恢复成功率、恢复时间、掉落，失败全部计入分母 |
| R1 | 外部参考 | 完整连续单轴转笔，官方`02_continuous_single_axis`，4条 | 从首帧到末帧的完成率、笔位置/方向误差、失败片段 |
| R2 | 外部参考 | 完整连续多轴转笔，官方`03_continuous_multi_axis`，9条 | 同上，并分接触切换阶段定位失败 |

C1/C2检查精度和接触恢复，R1/R2直接学习完整外部轨迹；两部分可并行开发，不要求把若干微动作逐项练完才进入参考动作。四任务联合策略使用同一物理F和目标条件actor/critic，目标包含任务、相位和预给参考；不能用四个独立策略冒充联合策略。

## 3. 环境、模型与训练闭环

每轮执行：按任务分配环境采集→保留真实终止前状态与目标相位→按任务均衡采样连续窗口拟合F→从回放恢复起点→逐步推进参考和预测传感状态→BPTT更新actor→TD(λ)更新critic。

| 项目 | 首轮提案 |
| --- | --- |
| 四任务采样 | C1/C2/R1/R2各25%；R1/R2组内按clip均匀，避免长clip占据全部回放。两能力组为50/50；单参考组按clip均匀 |
| 起点 | actor/critic/F均随机；在线模型预热3000次，期间持续采集。发布策略仅作参考阳性回放，不当教师；旧checkpoint不热启动新主结果 |
| SM起始配置 | 每进程2048环境；模型/actor batch8192；k8、H32；10次F更新/actor更新；UTD候选0.4（2/3向量步调度）；critic 5 epochs×4 mini-batches |
| 学习率 | actor/F/critic各2e-4、γ0.99、λ0.95；不随batch自动放大学习率。critic统计优先真实数据，失败监督与F梯度隔离；旧筛选完成后给出最终选择，不能把旧10Hz胜出直接当新任务最优 |
| PPO | 同环境/观测/动作/奖励/终止/初始化网络规模；rollout32、minibatch8192、4 epochs；沿用已验证PPO损失与调度初值1e-4 |
| 信息边界 | 两算法actor同样读取本体/触觉历史、参考目标和共同模拟视觉位姿测量；明确噪声、延迟和采样频率。其部署端估计器未验证，属于状态估计输入实验，不能称已端到端视觉部署 |
| 特权信息 | 真实物理状态和随机化参数只供F/critic、奖励及评测；预给未来目标合法，真实未来传感/接触不能进入actor想象 |
| WSM | 本轮先做强SM与PPO。新物体和50Hz改变先验分布/时间语义；之后先核验传感与时间适配，再接入兼容WSM，不把10Hz隐状态在50Hz盲更新 |

上述批量和H32未实测；512环境/H16旧试跑不等于该配置通过。新任务模型结构、额外目标/传感字段、200Hz物理成本都要进入容量与吞吐验收。旧动作接口checkpoint若不兼容，显式拒绝加载。

## 4. 资源优化与四卡实验安排

目标约24GiB/卡；建议每卡SM＋PPO两个进程、每进程2048环境/batch8192。先测单进程，再同卡双进程；总峰值超过28GiB时降为1536/6144，仍不合适再按实测收缩。原22–28GiB外推来自旧方块/H16，不能用于证明新笔任务/H32显存已满足。

| 空闲GPU角色 | 进程A | 进程B | 对照回答的问题 |
| --- | --- | --- | --- |
| A | SM联合C1+C2+R1+R2 | PPO联合C1+C2+R1+R2 | 同一策略能否覆盖四任务、SM效率如何 |
| B | SM能力组C1+C2 | PPO能力组C1+C2 | 精度/恢复是否可学，便于定位失败来自基础控制还是多动作干扰 |
| C | SM参考R1 | PPO参考R1 | 连续单轴动作的可学习性及算法差异 |
| D | SM参考R2 | PPO参考R2 | 连续多轴动作的可学习性及算法差异 |

不是四卡同种子重复实验，而是4个问题×2种方法；首轮同一配对种子，不能声称跨训练种子显著性。联合组与分组使用相同总环境数，因此单任务得到的交互预算不同；逐任务记录交互/更新和成本。比较联合学习相对三个分组的总成本时，须累计全部分组训练，不能只比较某一条曲线。

每进程最多12小时，其中最多11小时在线训练/开发评估，末1小时最终评估和保存；按首次启动固定deadline。四卡同时使用上限为48物理GPU小时、96进程小时，两者分开记账。同卡进程不能各冒记12小时独占GPU成本，也不能仅按GPU-util公平分摊；另记更新/交互数、CUDA阶段时间和同卡吞吐影响。短试跑成本单列。不自动延长或恢复。

目前21:33的只读快照：GPU0为其他项目进程；GPU1/2继续S2/S5筛选；GPU3空闲。A–D是未来空闲卡角色，不是已获四卡独占。现有筛选保持23:20原硬截止，其他项目进程不动。

计算优化顺序：

1. 已实现的合并数值检查保留；旧学习阶段短测降低约4%–8%，同RNG更新差异为0。
2. 减少循环内标量回传、批量日志与合法回放索引缓存；验证数值检查、采样分布和episode边界不变，再考虑固定shape纯tensor融合。尚未实现。
3. 训练与评估进程解耦，评估不可变轻量actor快照；按GPU总峰值准入，容量不足时排队，不能默认往双任务卡再加第三进程。完整恢复快照保留且错峰写盘。尚未实现。
4. 四任务在同一批次并行；固定资产/参考预处理缓存，避免短试验反复加载。模型、回放、归一化、优化器与RNG每次从头实验独立重置。
5. 暂不把DDP、混合精度、异步collector/learner与上述改动叠加。当前V100沿用验证过的FP32，数值或数据滞后变化另做受控试验。

新代码和轨迹适配完成后，理想四卡空闲时短试跑约1.5–2.5小时；具体耗时以仿真和评估实测为准。参考动作不为了赶截止改成慢放、截短或简单正反转。

正式评估：

- C1/C2拟各200回合锁定条件；成功角度容差、保持时间、扰动冲量在物理阳性试跑后、任何学习调参前固定。它们是能力诊断，不是外部论文阈值。扰动幅度不能按某策略是否成功事后修改。
- R1/R2逐clip32个锁定种子，从首帧运行到末帧；4×32＝128、9×32＝288回合。联合策略共816回合最终测试。开发使用另一组种子且保持每clip等权；不把同一录制切片当独立泛化样本。
- 参考训练代码的失效条件为位置误差>5cm、笔轴方向误差≥60°；原`play`模式将位置阈值放宽到20cm并移除方向终止。正式eval必须独立固定前一组条件，并记录到达reference_end；不能调用放宽后的演示模式统计成功。5cm/60°是可追踪的失败边界，精度仍需报告连续误差分布，不以“未终止”表示高精度。
- 参考库旋转指标是笔轴方向，而非完整SO(3)滚转误差；保留原定义，轴对称笔的自转另列时注明。相机噪声/随机化、域参数、初态和仿真数值设置对所有方法一致。
- 报告逐动作/逐clip成功数、最差动作、全部回合误差与失败列表、完成度、到相同成功水平的墙钟和GPU成本；回报保留诊断用途。首次只检验库内覆盖和新扰动种子鲁棒性，不宣称未见轨迹泛化。
