## 策略训练入口

`scripts/run_training.sh` 提供 `collect / merge / prepare / calibrate / validate / sm / evaluate / night` 子命令，均可追加 `--help`。

SM 适配使用原 actor 权重，执行 4 步想象与 BPTT，单独训练价值网络。世界模型、失败头和观测归一化统计在 actor 更新中冻结，梯度仍通过其输入传播。动作路径包含噪声、低通滤波、逐环境目标步长和关节目标裁剪。

已完成 200 次策略更新，并重载 checkpoint 续训至第 225 次。actor 与原推理路径输出最大差异为 0，观测与 RSSM 输入梯度均非零；模型、失败头和归一化统计未变。四项回归检查覆盖动作缓存别名、失败与超时的价值自举差别、常数失败分类器及终止窗口掩码，全部通过。

相同 seed=123、8 个完整 episode 的物理评估：原策略平均回报 1073.56，更新策略 1019.41（下降 5.04%），两者均 0 次失败、8 次超时。当前仅验收训练链路，尚无性能提升证据。

`night` 顺序执行策略更新、真实物理评估、采集、恢复起点和预测头校准。候选策略回报低于基线 90% 或 8 个 episode 中失败超过 1 次时，不采用该策略继续采集。预测校准不通过时不会继续更新 actor。
