## 改动依据及风险

**A：风险较低，属于可检验的参考实现对齐，尚未证明提高回报。** 原手部参考先对预测状态停止梯度，再拟合失败头。旧实现的失败BCE会修改F，有把物理预测变成分类捷径的可能。候选只切断“失败监督→F”这一训练梯度；失败头继续学习，actor想象时仍保留通过失败概率与物理状态的输入导数。网络输出、checkpoint格式、奖励、动作、终止条件不变。

**B：实现风险较低，计算和实验解释风险高于A。** 将初始模型更新从200增至3000次，每10次更新增加8个向量步的随机策略采集。actor参数在此阶段不更新，避免仅在固定小回放上重复拟合。代价是更晚开始策略更新；新数据、normalizer统计和预热量共同变化，因此将其报告为“加强在线预热”整体，不能单独归因于更新次数。全部耗时和采集量计入预算。

暂不修改失败采样权重、critic归一化、奖励、想象长度或学习率，避免在午夜前叠加尚未验证的变化。两候选保持64环境、k8/H8、每轮10次模型拟合、相同actor/critic及评估协议。
