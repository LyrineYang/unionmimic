## 分开三个可检验假设

**H1：策略上下文。** `a = π(o_history, g, ψ(h))` 是否比同样保留观测历史的 SM 策略更准确地处理接触变化？第一版保留独立的 `s_next = F(s, u, ξ)`，不要求先验提高 F 的预测精度。

**H2：真实与想象中的上下文一致性。** 相同动作序列下，想象得到的循环状态是否接近真实传感器更新的状态？降低这一差异能否减小动作/收益偏差，让 BPTT 学到的策略更可靠地回到仿真执行？这是优先研究的扩展，接入时就要记录诊断量；专门的一致性训练作为后续对照。

**H3：上下文辅助动力学。** 再比较 `F(s, u, ξ)` 与 `F(s, u, ξ, ψ(h))`，检验同一起点、同一记录动作下的预测误差和动作响应是否改善。若 F 已获得足够的物理状态与真实域随机化参数，历史上下文可能是冗余信息；不能人为删掉基线信息来制造收益。

H1 成功不能直接证明 H3。只给 actor 加 h，会改变采样到的动作和状态分布，但不会让固定 F 在固定输入/动作下自动变准确。“更会展开未来”在报告中必须具体指预测精度、上下文一致性、可信展开时长或策略梯度效果中的哪一项。

## 方法与验收顺序

1. **建立足够强的 Sharpa SM 基线**：独立物理动力学、随机 actor/critic、完整交替循环；对照有训练证据的复现库，逐项审查训练细节和 Sharpa 适配，通过诊断、单因素实验优化设置。交付经过真实控制评估的固定代码、配置和权重，不能以工程检查通过结束本项。具体任务见 [SM_REPRODUCTION.md](SM_REPRODUCTION.md)。
2. **接入冻结先验**：实现 ψ、真实历史恢复、每一步想象上下文更新；actor 与 ψ 学习，WSM 权重冻结。特权状态只用于模型/critic 训练，不泄漏给可部署 actor。
3. **完成第一主比较**：配对种子、相同任务与预算，测精度及成本。更多传感器或参数造成的收益先如实计为整个方案收益。
4. **检验 H2**：比较基础接口与一致性训练，控制数据与辅助训练预算；对照同容量历史编码器、随机/从头 WSM，判断预训练贡献。
5. **有证据后再选 H3、在线 WSM 适配或可信视野实验**：每次改变一个因素，不同时叠加所有扩展。

完整接口见 [ARCHITECTURE.md](ARCHITECTURE.md)，假设、相关工作和拓展见 [INSIGHTS.md](INSIGHTS.md)，各阶段交付见 [ROADMAP.md](ROADMAP.md)。

## 关键接口决策

真实 WSM 输入含深度与触觉；SM 的物理状态预测不自动等于完整 WSM 观测。目标接口是“用预测观测/观测特征递归更新 WSM”。需显式实现并验证传感器或 encoder-feature 桥接，不能以缺失模态补零代替验证。

此前讨论的 WSM action-only prior 展开保留为较简单的候选/消融；它不读取 SM 预测观测，不与用户给出的观测条件递归公式等价。两条路线都不允许拿真实未来观测给策略想象纠错。具体采用哪条接口，由同一组记录动作下的状态、动作偏差和吞吐测试决定并在正式比较前固定。

冻结权重不冻结内部状态，也不意味着把前向包进 `no_grad`。actor 更新时应保留通过 F、上下文更新及 ψ 的输入导数；是否使用额外停止梯度是要标注的算法变体。
