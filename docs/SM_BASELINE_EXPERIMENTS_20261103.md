## 目标与本轮选择

目标是找到当前任务中可重复、稳定且计算成本合理的SM配方，再交给SM＋WSM主比较。论文的高回报、低失败和学习效率是优化方向，不能把G1/LAFAN1的0.82、1.2小时硬套到Sharpa回报或V100耗时。本轮只能确定四种配方中的候选优胜者，不声称全局最优或已完成论文数值复现。

## 审核依据与已实现改动

1. **失败采样**：固定LEAP参考 `0ab03eb2244b4a1a020d94ef38a4823bb9e15ba0` 的 `train_yaw.py` 对失败重采样、停止失败监督对F的梯度；`train_ftrot.py` 586–604行有重要性修正。这里采用一阶有效转移混合，`q=(1-f)p+f p(.|failure)`，BCE权重为`p/q`。只影响失败头训练，不改变物理损失、真实终止或想象失败概率上限。无失败样本时退回均匀采样，不伪造失败。该具体组合是Sharpa适配，并非照搬某库整套配方。
2. **critic统计**：[YHFone trainer](https://github.com/YHFone/supermimic-mjlab/blob/main/src/supermimic/algo/trainer.py) 的 `_update_critic_normalizer` 明确只用真实转移。本项目C/D沿用Collector在真实采集时更新统计，关闭想象阶段的统计更新；保留critic学习及actor经过critic输入的梯度。
3. **恢复修复，四组共用**：原worker只恢复learner/replay/RNG，新仿真器的重力课程级别、2048回合统计窗口和写入索引会重置。新版本保存/恢复完整课程并在恢复级别开始新episode；启动重置不计为训练失败。仍不声称恢复PhysX接触求解器内部状态。无时间退火的随机化在新episode重新采样，物理轨迹不跨进程拼接。
4. **诊断与选权重**：新增独立留出转移上的失败Brier、预测/真实发生率及阳性数。开发集先优先选择失败≤5%且旋转≥28.2059 rad的checkpoint，再按回报；无合格者保留最高回报但明确未达控制要求。所有组使用同一规则。

本轮暂不叠加EMA、失败概率裁剪、奖励加权、更大模型、H32或UTD0.4。手部参考的其他配方包含关闭随机推力、修改想象掉落惩罚等选择，这些会改变任务或优化目标，不能无标注搬入baseline。

代码完全隔离在 `unionmimic/online_baseline/`，入口 `scripts/train_online_baseline.py`。正在运行的原版与candidate源码哈希在修改前后核验；不热改原1/3号。

## 与论文、任务和信息边界的核对

论文依据：[SuperMimic，算法A.1、表A.4/A.5、实验与评估](https://arxiv.org/pdf/2610.28480)。以下差异必须随结果报告，不使用“与论文同配置”描述本轮。

| 项目 | 论文 / 本轮 | 审核结论 |
| --- | --- | --- |
| 平台与目标 | G1运动追踪 / Sharpa单物体z轴旋转 | 算法适配；原论文回报、误差和加速比不可直接套用 |
| 硬件 | H100等 / 单组一张V100 | 四卡是四个实验，不是四卡数据并行；调参总成本另计 |
| 仿真并行 / batch / replay | 4096环境、模型batch2048、actor4096、replay1000步 / 64、256、256、512 | 已知资源/吞吐适配，可能限制覆盖；本轮先固定，下一轮再有针对性测试 |
| 模型 / actor / critic | 动力学和actor更大、critic256–128 / F512×3、actor512–256–128、critic256–128 | 容量差异明确记录；四组一致 |
| 历史与视野 | 10帧、H32×0.02s / 4帧292维、H8×0.10002s≈0.80016s | 不仅比较步数；本轮不盲增H32到3.2秒 |
| 训练循环 | k8、10次F拟合、Adam、γ.99、λ.95、critic5×4 / 相同 | 复现核心更新路径；actor梯度norm1再value0.1 |
| UTD / 学习率调度 | 0.4、余弦250k迭代 / 每8向量步1次actor=0.125、固定2e-4 | 已知差异，不称严格等设置；下一轮按覆盖/梯度诊断决定调整 |
| 部署actor | 历史观测＋任务目标 / 关节、控制目标、带噪触觉、已知轴的四帧历史 | **无物体真值、质量、摩擦、未来状态、奖励或终止标签输入actor** |
| F/critic | 训练物理状态和仿真上下文 / 177＋93维 | 仅训练使用的特权信息符合此方法角色；不可把F/critic接口伪装成可部署actor输入 |
| 想象数据 | 模型递推 / 当前真实起点＋预测状态递推 | 记录未来状态/动作仅用于F监督；actor想象不读未来记录观测/奖励/失败标签 |
| 评测与成本 | 原论文协议 / 当前带原任务噪声、随机化的固定完整回合；全部评估计费 | 四组同口径；不得把发布策略冻结推断当从头训练成本 |
