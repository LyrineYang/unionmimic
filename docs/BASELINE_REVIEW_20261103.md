## 4. 原四组设计为什么只改变两项

它已经继承梯度隔离和加强预热，另外两项为失败采样和critic统计；UTD与H暂时固定，避免同时改变多个未经验证的梯度/数据环节。

原四组A00/B10/C01/D11分别为“原采样＋混合统计”“失败采样＋混合统计”“原采样＋真实统计”“失败采样＋真实统计”。可比较B−A与D−C估计采样影响，C−A与D−B估计统计影响，D−B−C＋A检查交互。这是对这两项解释清楚的设计；缺点是花36 GPU小时仍没覆盖UTD/H。用户提出资源顾虑后，不再默认每两个因素都开四组9小时。

### 阶段S：四因素联合短分支筛选，最多12 GPU小时
