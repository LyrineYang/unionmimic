| 网络 | F 3×1024/LN/SiLU；Actor 512–512–256/ELU；critic 256–128/LN/SiLU；不再使用旧小规模配方 |
| 物理与控制器 | 16→22关节；手基座坐标/wxyz；实际控制步约0.10002秒；保持Sharpa动作滤波、相对目标累积、限位和动作随机化顺序 |
| 传感器与奖励 | 原Sharpa完整奖励保留；增加指尖/接触/力矩预测，供奖励与想象观测使用。非负接触力采用log-force损失；不删除难预测奖励项 |

4. 进程启动起总墙钟最长12小时，包含初始化、试跑和评估；末10分钟预留最终评估。中途每约2小时做固定开发种子的512回合评估，以原生平均回报选择本轮best，并同时报告旋转量、偏轴与失败率。
